# friends-newsletter

**Postcards from Shashank** is a short, seasonal, airmail-style postcard for friends around the world: life updates, photos and video, and an easy way for friends to write back.

- [`docs/product-vision.md`](docs/product-vision.md): research on what's out there, product principles, anatomy of an issue, the reply loop, tech plan, roadmap
- [`prototype/issue-01.html`](prototype/issue-01.html): design prototype of issue No. 01, with sample content and illustrated placeholder photos

The prototype is an HTML fragment (no `<html>`/`<head>` wrapper) so it can be published as a Claude artifact; it also opens directly in a browser.
